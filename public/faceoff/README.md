# Face Off drawings

Put one drawing per character in this folder, named `<id>.png` (for example `ayu.png`).
Each should be square (about 512×512), head and shoulders, on a plain or transparent background.
Until a file exists, the game draws a simple placeholder face instead.

**Each drawing must match its traits.** The game answers questions from this table, not from the picture.
To change a character, edit `convex/lib/faceoff/roster.ts` and keep every row unique.

Notes for drawing:
- A character with a hat should still show a bit of hair colour under it (except the bald ones), so "Is their hair red?" stays fair.
- Skin tone, eye colour, expression and pose are free. No question asks about them.
- Hair colour should read clearly at small size: the board shows faces at about 55 px wide.
