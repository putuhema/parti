# Pixel Atlas picks

456 candidate sprites for Raja Silat, picked by caption from
[Angais/pixel-art-atlas-1.4m](https://huggingface.co/datasets/Angais/pixel-art-atlas-1.4m).
Open `index.html` to browse them enlarged; `manifest.json` lists each sprite's caption and dataset row.

- **Groups:** prison objects (keys, chains, ball and chain, crates, barrels, dynamite, gongs, drums, torches…),
  weapons (kris daggers, swords, whips, staffs), Pusaka ideas (fez, scarves, bracelets, coffee, sandals,
  rings, tonics, cloth), icons (dice, shields, hearts, hourglass, crowns, skulls, potions, campfires, chests…),
  and chess pieces (pawn, knight, bishop, rook, queen, king, boards).
- **Size:** 16×16 PNGs with transparent backgrounds. Scale by whole numbers (×4, ×5…) with nearest-neighbour
  filtering (`image-rendering: pixelated` on the web, "Nearest" texture filter in Godot) to keep them crisp.
- **Captions are approximate** (the dataset says so): the "kris" daggers are straight blades, and "prayer beads"
  are characters wearing necklaces. Check each sprite by eye.

## Re-running
`scripts/pixel-atlas-find.py` (search captions; needs `duckdb`), `scripts/pixel-atlas-download.py`
(download, resumable; `WORKERS=1 PAUSE=1.2` avoids rate limits), `scripts/pixel-atlas-sheet.py art/pixel-atlas`
(rebuild `index.html`).
